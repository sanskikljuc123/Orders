# Orders

Learning project: a small Orders app (ASP.NET Core API + web UI, Keycloak login, Postgres,
fake payment service) with unit, integration and E2E tests, a NUKE build, GitHub Actions and a
Helm chart generated by .NET Aspire. Project rules and conventions are in [`CLAUDE.md`](CLAUDE.md).

## Prerequisites

| Tool | Needed for |
|---|---|
| .NET SDK from [`global.json`](global.json) (10.0.1xx) | everything |
| Docker (running) | `aspire run`, integration tests, E2E |
| PowerShell (`pwsh`) | installing the Playwright browser for E2E |
| Helm 3.22.1 | `./build.sh --target Helm` only |

`dotnet tool restore` installs the Aspire CLI and GitVersion from `dotnet-tools.json`
(the build does this for you).

## Run the app

```bash
dotnet tool restore
dotnet aspire run
```

This starts Postgres, Keycloak (with the test realm), the fake payment service and the API.
The console prints the **dashboard** URL with a login token; open it to see every resource and its
URL. The API/UI runs at http://localhost:5189 (launch profile `http`). Keycloak's port is
assigned by Aspire; find it in the dashboard.

Stop with `Ctrl+C`.

## Manual smoke check

With the app running, open http://localhost:5189 and check:

| # | Do | Expect |
|---|---|---|
| 1 | Open the page | "You are not signed in." and a **Log in** button |
| 2 | **Log in** as `ana` / `ana123` (Keycloak test user) | back on the page, "Signed in as ana" |
| 3 | Product `Smoke book`, quantity `2`, **Place order** | result "Order Paid" |
| 4 | Look at **My orders** | "Smoke book (Paid)" |
| 5 | Clear the product, **Place order** | "Validation error" |
| 6 | `curl -i -X POST http://localhost:5189/orders -H "Content-Type: application/json" -d '{"productName":"Book","quantity":1}'` | `401 Unauthorized` (no login) |

Also: `curl http://localhost:5189/health` returns `Healthy`. To see a declined payment, switch the
fake: `curl -X POST <payment-url>/__admin/mode -H "Content-Type: application/json" -d '{"mode":"decline"}'`
(payment URL from the dashboard; `/__admin/reset` switches back). The test users and the fake's
contract are for local use only (see `CLAUDE.md` and `src/FakePaymentService/README.md`).

## Tests and build

What each risk is tested by: [`TESTING.md`](TESTING.md). Commands and quality gates (coverage,
mutation, stability, deployment smoke): [`CLAUDE.md`](CLAUDE.md).

```bash
./build.sh --target Test Helm Images
```

runs exactly what CI runs: compile, unit tests, integration tests (Docker), coverage gate,
Playwright browser install, E2E, `aspire publish` and `helm lint`/`helm template`. Single targets:
`--target UnitTests`, `IntegrationTests`, `E2ETests`, `Helm`. Plain `dotnet test tests/<Project>`
works too. On Windows use `.\build.cmd`.
